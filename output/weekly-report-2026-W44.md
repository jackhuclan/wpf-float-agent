# 周报｜Floaticon（wpf-float-agent）

**周期**：2026-10-26（周一）～ 2026-10-30（周五）
**交付**：20 次提交 / 15 个版本发布（v1.3.1 → v1.9.4）/ CI 与 publish-nuget 每次双绿 / NuGet 包同步 GitHub Packages

---

## 一、本周概要

本周主攻三条线：**把悬浮助手从"能聊天"推到"能干活"**（内置文件工具 + 写操作人工确认 + 会话管理与持久化）、**RecipeDemo 演示外壳落地并可被 AI 驱动**（配方拉平技能 + 11 个工具打通）、**工程基建制度化**（每次改代码必发版、CI 版本门禁、工具调用可追溯）。

关键数字：
- 版本：15 个（1.3.1 / 1.3.2 / 1.4.0 / 1.5.0 / 1.6.0 / 1.7.0 / 1.7.1 / 1.7.2 / 1.8.0 / 1.8.1 / 1.9.0 / 1.9.1 / 1.9.2 / 1.9.3 / 1.9.4）
- 新增能力：会话自动保存与全生命周期管理、内置 read_file/write_file、写前确认卡、工具执行日志、RecipeDemo 外壳 + 拉平技能链路
- 验证：console 探针 26 用例（文件工具）、11 工具全链路探针、会话/抽屉/删除/Popup/窗口退出等 6 组 GUI 行为探针

## 二、关键交付

### 1. 悬浮助手交互（v1.3.1）
- 用户气泡悬浮显示操作行：时间 + 复制按钮，跨天自动切日期格式；hover 判定扩到整条消息行，修复"指针移向按钮时按钮消失、点不到"（根因：WPF 命中测试只认非 null Background，气泡与操作行之间的 4px 间隙穿透）。
- 聊天窗/配置窗标题栏按钮 hover 重做：半透明白叠加 + 关闭按钮 Windows 惯例红色高亮，消除与靛蓝标题栏撞色的系统默认灰（v1.7.1）。

### 2. RecipeDemo 演示外壳（v1.4.0 / v1.5.0 / v1.9.4）
- 新增独立演示工程：左侧配方树（搜索/折叠/收展）+ 右侧五视图（Summary / Wafer Map / Alignment / Tests / Recipe-Run Parameters），引用 FloatAgent 同时显示悬浮球。
- 打通 alignment 技能与 11 个 AI 工具（选择配方、切视图、找圆心、建模板、粗/精定位、define_llc、保存），工具在后台线程调用、经 Dispatcher 回 UI，失败分支按真实工艺规则拦截；配套 `docs/alignment-flow.md` 流程图（Mermaid 源码 + 渲染 PNG）。
- 生命周期收敛：主窗关闭即整个应用退出（含悬浮球），不再残留只有悬浮球的后台进程。

### 3. 会话能力（v1.6.0 / v1.9.0～v1.9.3）
- 会话自动保存：一对话一文件 `sessions/<guid>.json`，原子写（.tmp + Move），标题取首条用户消息。
- 会话管理抽屉（需求提取自 MegaAgent PRD FR-3/FR-4/B15）：标题栏「☰」滑出覆盖式抽屉，新建 / 切换 / 行内重命名 / 删除二次确认全生命周期，列表项显示相对时间与当前会话高亮，坏文件降级跳过。
- 三轮回修：抽屉宽度（50% + 30% 黑遮罩，原为 100%）、收起后弹出菜单残留、列表滚动条与消息区统一；副标题去掉消息数；删除会话不再产生多余「新会话」文件。

### 4. 内置文件工具与写操作确认（v1.8.0 / v1.8.1）
- `read_file`：行号分页（默认 2000 行）、单行截断、二进制与 >10MB 拒绝；`write_file`：写前聊天窗确认卡人工放行、覆盖写、自动建父目录、UTF-8 无 BOM。
- `WorkspaceScope` 白名单：运行目录 + `config.json` 可选 `WorkspaceRoots`（动态生效），`config.json` 读写全拒防 API Key 泄露；确认请求隐藏时自动弹出聊天窗，拒绝/超时 120s/停止均不落盘。
- 确认卡从窗口内联代码拆为独立 `WriteConfirmationCard` 控件 + 专属 ViewModel（v1.8.1）。

### 5. Agent 能力与可追溯性（v1.7.0）
- 拉平技能依实跑反馈优化：新增"事实只认两个来源 / 被质疑先定事实不迎合 / 返回值如实引用"三条原则与反例。
- 全量工具调用日志（时间/名称/参数/结果/耗时）+ 内置 `query_tool_history` 工具，根治模型凭记忆断言调用历史的问题。

### 6. 工程基建
- 发版流程制度化并写入 AGENTS.md：改版本 → 同步 README 中英 + PRD → 打包带版本号 nupkg → 代码/文档/包同批提交推送。
- CI 版本门禁：publish-nuget 在 push 的最新提交改了代码却未升 `<Version>` 时直接失败，杜绝"静默跳过不出包"。
- 日志规范化：会话持久化失败由 Debug.WriteLine 升级为 `ILogger` LogError。
