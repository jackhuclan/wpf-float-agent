# Alignment（配方拉平）

## 目标

把"拉平"拆成 4 个阶段、12 个动作。每个动作只做一件事，做完即汇报并停在人工确认卡点，确认后才推进下一步。

## 核心原则

1. **一次一步**：一次只发起一个工具调用（同一视图内的开关+计算可算作一步，但必须串行执行）；返回后先汇报结果，再等确认。
2. **每做一步前要提醒**：每次调用工具前，要提醒用户，即将进行什么操作。
3. **禁止跳步、并步、抢跑**：不得预判用户会同意，不得"顺便"把下一阶段也做完。
4. **确认即放行**：用户明确回复"继续 / 下一步 / 好 / OK / 可以"才视为放行；含糊回复、提问、纠正参数一律视为未确认，停在原地答疑。
5. **失败即停**：工具报错或返回状态非成功时立即停止流程，原样转述错误信息，给出可选处置建议，等用户决定；同一工具最多重试 1 次。
6. **不猜参数**：调用前先确认工具的真实 schema 和必填参数，不臆造默认值、不虚构返回值。工具不可用时，直接告知用户并终止流程。
7. **界面弹窗也是结果**：工具返回成功，但用户反馈界面上出现报错弹窗（如 "Please select 2-4 fields"）时，同样按失败处理，先解决弹窗问题再继续。

## 工具契约

| 阶段 | 工具                           | 作用                 |
| -- | ---------------------------- | ------------------ |
| 0  | `select_recipe`                | 选择配方    |
| 1  | `open_alignment`             | 从配方跳转到拉平界面         |
| 2  | `switch_to_edge_alignment`   | 切换到 Edge 视图（拉平前视角） |
| 2  | `calculate_wafer_center`     | 自动寻找晶圆圆心，成功后自动把载台移动到圆心位置；返回真实成功/失败结果 |
| 3  | `switch_to_coarse_alignment` | 切换到粗定位视图           |
| 3  | `create_recipe_template` | 创建配方模版           |
| 3  | `run_coarse_align`               | 执行粗定位，返回真实的成功/取消/中断/失败结果 |
| 4  | `switch_to_fine_alignment`   | 切换到精定位视图           |
| 4  | `create_recipe_template` | 创建配方模版           |
| 4  | `run_fine_align`                 | 执行精细拉平             |
| 4  | `define_llc`                 | Updating LLC：按当前轴位置计算 WCS 坐标、重绘 WaferMap 并把载台移动到 Field0 LLC。**必须先经人工确认 LLC 后才能调用** |
| 4  | `save_recipe`                 | 保存配方，返回真实的成功/失败结果 |

## 执行流程

### 阶段 0 · 选择配方

1. **快速通道**：如果目标配方已经在界面中打开（用户说明"配方已打开 / 已找到"），或者用户在做拉平时已明确指定该配方且界面中已可见，**跳过本阶段，直接进入阶段 1（进入拉平界面）**。
2. 否则调用 `select_recipe` 选择配方。
3. 根据返回值分支：
   - 返回"**找到了您需要的配方X**"：配方已在界面中打开，**直接进入阶段 1，无需再次确认**；
   - 返回"**找到多个配方**…"：把返回值中列出的候选名称整理成选项让用户选定，**不替用户选**；用户选定后用该唯一名称重新调用 `select_recipe`。
   - 返回"**没有找到配方**…"：告知用户未找到，请其给出准确配方名称后重试；**禁止猜测或编造配方名再次调用**。

### 阶段 1 · 进入拉平界面

1. 提醒"即将进入拉平界面"，然后调用 `open_alignment`。
2. 汇报："已进入拉平界面"，然后询问是否继续到圆心定位。

### 阶段 2 · 圆心定位（Edge 视图）

1. 串行执行：调用 `switch_to_edge_alignment` 切换到 Edge 视图；确认成功后再调用 `calculate_wafer_center`。
2. 根据返回值分支：
   - 返回"**成功找到圆心**…"（该操作已自动把载台移动到圆心位置）→ 汇报"已自动找到圆心并把载台移动到圆心位置"，然后询问是否继续到粗定位。**找圆心为全自动步骤，不设置人工确认卡点**。
   - 返回"**自动寻找圆心没有成功**…"：按核心原则 5 失败即停，原样转述，请用户确认晶圆是否完整出现在相机视野中；用户调整后可重试一次，仍失败则停止流程。

### 阶段 3 · 粗定位

1. 调用 `switch_to_coarse_alignment` 切换到粗定位视图。
2. 提示："请在画面中框选 ROI 区域，框选完成后回复我"。**等待用户明确回复**后再继续，不得自行假定 ROI 已选好。
3. 调用 `create_recipe_template` 创建配方模版。
4. 调用 `run_coarse_align` 执行粗定位。根据返回值分支：
   - 返回"**成功执行粗定位**"→ 第 5 步；
   - 返回"**拉平执行被取消 / 被中断**"或"**执行拉平失败：…**"→ 按核心原则 5 失败即停，原样转述；
   - 工具返回成功但用户反馈界面出现报错弹窗 → 同样按失败处理（核心原则 7）。
5. 得到成功结果后，然后询问是否继续到精定位。

### 阶段 4 · 精定位

1. 调用 `switch_to_fine_alignment` 切换到精定位视图。
2. 提示："请在画面中框选 ROI 区域，框选完成后回复我"。**等待用户明确回复**后再继续，不得自行假定 ROI 已选好。
3. 调用 `create_recipe_template` 创建配方模版。
4. 调用 `run_fine_align` 执行精细拉平。
5. **【人工确认卡点 · LLC】**精定位成功后，提示：
   > "精细拉平已完成。请人工到精定位界面上检查并确认 LLC（核对画面与 LLC 结果是否正确，如需调整请先手动调整），确认无误后回复我'LLC 已确认'，我再执行 Updating LLC。"

   **必须等待用户明确回复确认**（如"LLC 已确认 / 确认无误 / 可以"）才能继续；含糊回复、提问、纠正一律视为未确认，停在原地答疑。不得自行假定 LLC 已确认。
6. 用户确认后，提醒"即将调用 define_llc 执行 Updating LLC"，然后调用 `define_llc`。
   注意：执行时界面会再弹出一次"Updating LLC will redraw the wafermap…"确认框，请提醒用户点 OK；该操作会**重绘 WaferMap 并把载台移动到 Field0 LLC 位置**。
7. 调用 `save_recipe` 保存配方：
   - 返回"**保存配方成功**"→ 请用户顺带确认界面上没有报错弹窗，确认后输出完成汇报并结束流程；
   - 返回"**保存配方失败**…" → 原样转述，请用户检查界面弹窗（如 "Please select 2-4 fields！"）并处理后重试一次，仍失败则停止流程。
8. 汇报最终结果并结束流程。

## 全程状态记录

流程推进过程中维护并随时可复述以下状态，便于中途中断后接续：

| 项     | 说明                                        |
| ----- | ----------------------------------------- |
| 当前配方  | 阶段 0 选定的配方名                               |
| 当前视图  | Recipe / Alignment / Edge / Coarse / Fine |
| LLC 人工确认 | 未确认 / 已确认（阶段 4 调用 define_llc 的前置条件）       |
| 已完成阶段 | 0 / 1 / 2 / 3 / 4                         |
| 待确认动作 | 下一步是什么，等用户回复什么                            |

用户中途打断或提问时，先复述该状态再回答，不要凭记忆推断已经做到哪一步。

## 完成汇报模板

拉平结束后输出：

- 配方：<名称>
- 圆心：<找到 / 未找到>
- 粗定位：<成功 / 失败>
- 精定位：<成功 / 失败>
- LLC：<人工已确认，Updating LLC 成功 / 失败>
- 结论：拉平完成 / 在某阶段中止（原因）

## 反例（严禁出现的行为）

- ❌ 用户选完配方后，直接连着调用 `open_alignment` 和 `switch_to_edge_alignment`。
- ❌ 上一个阶段的任务没有完成，就直接跳到下一个阶段。
- ❌ 配方模版没有创建成功，就调用 `switch_to_fine_alignment`切换到精定位视图。
- ❌ 配方模版没有创建成功，就调用 `run_coarse_align`和 `run_fine_align`。
- ❌ 提示用户选 ROI 后，未收到回复就调用 `run_coarse_align`。
- ❌ 提示用户选 ROI 后，未收到回复就调用 `run_fine_align`。
- ❌ 工具返回成功但用户反馈界面有报错弹窗时，仍继续推进下一阶段。
- ❌ 精定位完成后，未收到人工"LLC 已确认"的明确回复就调用 `define_llc`。
- ❌ 用户对 LLC 提出疑问或要求调整时，仍继续调用 `define_llc`。
- ❌ 把"要不要继续"合并成一次提问，覆盖后续多个阶段。
- ❌ 工具失败后自行重试多次或改为猜测参数重调。
- ❌ 编造"已完成"掩盖未执行。
